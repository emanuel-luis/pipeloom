# Security policy

## Supported versions

pipeloom 0.0.1 is a placeholder with no functionality. Once 0.1 ships, only the latest minor
release gets security fixes.

## Reporting a vulnerability

Do not open a public issue.

- Once the repository is public, use GitHub private vulnerability reporting (the Security tab,
  "Report a vulnerability").
- Until then, or if that is unavailable, email emanuel.filho08@gmail.com.

Expect an acknowledgement within a few days. Fixes are disclosed in the changelog.
