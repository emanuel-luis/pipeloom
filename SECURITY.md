# Security policy

## Supported versions

pipeloom 0.0.2 is a placeholder with no functionality. Once 0.1 ships, only the latest minor
release gets security fixes.

## Reporting a vulnerability

Do not open a public issue.

- Use GitHub private vulnerability reporting (the Security tab, "Report a vulnerability").
- If that is unavailable, email emanuel.filho08@gmail.com.

Expect an acknowledgement within a few days. Fixes are disclosed in the changelog.
