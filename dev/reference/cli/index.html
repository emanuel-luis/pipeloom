    Command line¶

    pipeloom¶

    pipeloom: declarative, engine-agnostic data pipelines in YAML.

    Usage:

    pipeloom [OPTIONS] COMMAND [ARGS]...

    Options:

      --version  Show the version and exit.
  --help     Show this message and exit.

    pipeloom compile-¶

    Validate the project and write the plan to a manifest file.

    Usage:

    pipeloom compile- [OPTIONS]

    Options:

      --project-dir DIRECTORY    Directory that holds pipeloom.yml.  [default: .]
  --vars TEXT                Variables as a YAML or JSON mapping; they
                             override the vars block.
  --target TEXT              Target to bind; default_target or the only target
                             when omitted.
  --plugin MODULE:ATTR       A PluginSpec to load besides the installed
                             plugins. Repeatable.
  -s, --select SELECTOR      Models to include: name, tag:x, path:dir,
                             materialized:x, +model, model+, N+model, model+N.
                             Space unions, comma intersects. Repeatable, all
                             are unioned.
  --exclude SELECTOR         Remove the models this selector matches from the
                             selection. Repeatable.
  --log-format [text|json]   Diagnostics and events on stderr: readable text
                             or one JSON object per line.  [default: text]
  --boundary [process|task]  Where units run; default is the target's boundary
                             (process).
  --out PATH                 Manifest file, relative to the project dir unless
                             absolute.  [default: target/manifest.json]
  --warn-error               Exit 1 on warnings too.
  --help                     Show this message and exit.

    pipeloom graph¶

    Print the graph of the selected models, in dependency order.

    Usage:

    pipeloom graph [OPTIONS]

    Options:

      --project-dir DIRECTORY         Directory that holds pipeloom.yml.
                                  [default: .]
  --vars TEXT                     Variables as a YAML or JSON mapping; they
                                  override the vars block.
  --target TEXT                   Target to bind; default_target or the only
                                  target when omitted.
  --plugin MODULE:ATTR            A PluginSpec to load besides the installed
                                  plugins. Repeatable.
  -s, --select SELECTOR           Models to include: name, tag:x, path:dir,
                                  materialized:x, +model, model+, N+model,
                                  model+N. Space unions, comma intersects.
                                  Repeatable, all are unioned.
  --exclude SELECTOR              Remove the models this selector matches from
                                  the selection. Repeatable.
  --log-format [text|json]        Diagnostics and events on stderr: readable
                                  text or one JSON object per line.  [default:
                                  text]
  --output [text|dot|mermaid|json]
                                  Format of the graph: text (name <- parents),
                                  Graphviz dot, Mermaid or JSON.  [default:
                                  text]
  --help                          Show this message and exit.

    pipeloom ls [OPTIONS]

    Options:

      --project-dir DIRECTORY   Directory that holds pipeloom.yml.  [default: .]
  --vars TEXT               Variables as a YAML or JSON mapping; they override
                            the vars block.
  --target TEXT             Target to bind; default_target or the only target
                            when omitted.
  --plugin MODULE:ATTR      A PluginSpec to load besides the installed
                            plugins. Repeatable.
  -s, --select SELECTOR     Models to include: name, tag:x, path:dir,
                            materialized:x, +model, model+, N+model, model+N.
                            Space unions, comma intersects. Repeatable, all
                            are unioned.
  --exclude SELECTOR        Remove the models this selector matches from the
                            selection. Repeatable.
  --log-format [text|json]  Diagnostics and events on stderr: readable text or
                            one JSON object per line.  [default: text]

  --help                    Show this message and exit.

    pipeloom plugins list¶

    List plugins by group and kind. Nothing is imported unless --check is given.

    Usage:

    pipeloom plugins list [OPTIONS]

    Options:

      --group [engines|catalogs|state_stores|sinks|secret_providers|executors|renderers|naming]
                                  Only this group.
  --output [text|json]            [default: text]
  --check                         Import each plugin and report its API and
                                  status.
  --plugin MODULE:ATTR            A PluginSpec to load besides the installed
                                  plugins. Repeatable.
  --log-format [text|json]        Diagnostics and events on stderr: readable
                                  text or one JSON object per line.  [default:
                                  text]
  --help                          Show this message and exit.

    pipeloom run¶

    Run the selected models. Exit codes: 0 ok, 1 a unit or a check failed, 2 bad usage, 130 stopped.

    -s unit:NAME runs one unit without a lock or run results; the process executor uses it.

    Usage:

    pipeloom run [OPTIONS]

    Options:

      --project-dir DIRECTORY    Directory that holds pipeloom.yml.  [default: .]
  --vars TEXT                Variables as a YAML or JSON mapping; they
                             override the vars block.
  --target TEXT              Target to bind; default_target or the only target
                             when omitted.
  --plugin MODULE:ATTR       A PluginSpec to load besides the installed
                             plugins. Repeatable.
  -s, --select SELECTOR      Models to include: name, tag:x, path:dir,
                             materialized:x, +model, model+, N+model, model+N.
                             Space unions, comma intersects. Repeatable, all
                             are unioned.
  --exclude SELECTOR         Remove the models this selector matches from the
                             selection. Repeatable.
  --log-format [text|json]   Diagnostics and events on stderr: readable text
                             or one JSON object per line.  [default: text]
  --manifest FILE            Run the plan of this manifest instead of
                             compiling the project.
  --expect-plan-hash HEX     Stop with PLX103 unless the plan hash is this
                             sha256.
  --run-id TEXT              Name of the run. Reusing it continues that run.
                             Default: a timestamp and a suffix.
  --full-refresh BOOLEAN     Rebuild append tables from scratch. Takes an
                             optional true or false.  [default: False]
  --fail-fast                After the first failure, start no more units.
  --no-lock                  Do not take the run lock.
  --workers INTEGER RANGE    Units to run at once. Default: the target's
                             setting, else min(4, CPUs).  [x>=1]
  --boundary [process|task]  process runs units on threads here; task runs
                             each in its own process. Default: the target's
                             boundary.
  --warn-error               Exit 1 on warnings too.
  --help                     Show this message and exit.

    pipeloom schema export¶

    Write the JSON Schemas, with plugin options as oneOf branches.

    Usage:

    pipeloom schema export [OPTIONS]

    Options:

      --out DIRECTORY                Directory to write project.json, models.json
                                 and defaults.json into.  [required]
  --plugins [installed|builtin]  Plugins whose options appear in the schema;
                                 installed imports every plugin.  [default:
                                 installed]
  --plugin MODULE:ATTR           A PluginSpec to load besides the installed
                                 plugins. Repeatable.
  --log-format [text|json]       Diagnostics and events on stderr: readable
                                 text or one JSON object per line.  [default:
                                 text]
  --help                         Show this message and exit.
