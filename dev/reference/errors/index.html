    Error codes¶

    L0 parse¶

    PLY001¶

    YAML syntax error. Severity: error. Status: active. Since: 0.1.

    The file is not valid YAML, holds more than one document, contains a recursive alias, expands an alias above 100000 nodes, or uses an unsupported construct.

    PLY002¶

    Duplicate key. Severity: error. Status: active. Since: 0.1.

    A mapping repeats a key. Keys that arrive through a merge key are exempt: explicit keys win.

    PLY003¶

    Invalid encoding. Severity: error. Status: active. Since: 0.1.

    The file is not valid UTF-8 (a UTF-8 BOM is accepted) or has characters YAML forbids.

    PLY004¶

    File missing or unreadable. Severity: error. Status: active. Since: 0.1.

    pipeloom.yml or a model file does not exist or cannot be read.

    L1 schema¶

    PLS101¶

    Unknown field. Severity: error. Status: active. Since: 0.1.

    A key is not part of the schema. The message suggests the closest known field.

    PLS102¶

    Invalid value. Severity: error. Status: active. Since: 0.1.

    A value has the wrong type or fails a constraint.

    PLS103¶

    Unsupported config_version. Severity: error. Status: active. Since: 0.1.

    config_version is missing or not 1. It is checked first and stops schema validation.

    PLS104¶

    Literal value in a secret-like field. Severity: error. Status: active. Since: 0.1.

    A field whose name suggests a secret holds a literal. Use ${secret:...} or ${env:...}.

    PLS105¶

    Required field missing. Severity: error. Status: active. Since: 0.1.

    A mapping lacks a required field.

    PLS106¶

    Unresolved interpolation. Severity: error. Status: active. Since: 0.1.

    ${env:NAME} is unset with no default, or ${var:name} names an unknown variable.

    PLS107¶

    Malformed interpolation. Severity: error. Status: active. Since: 0.1.

    A ${env:...} or ${var:...} expression is malformed.

    PLS108¶

    Exactly one of several fields required. Severity: error. Status: active. Since: 0.1.

    Exactly one of a set of fields must be given, for example sql or python.

    L2 references¶

    PLR201¶

    Unknown ref. Severity: error. Status: active. Since: 0.1.

    An input names a model that does not exist. The hint suggests the closest name.

    PLR202¶

    Duplicate model name. Severity: error. Status: active. Since: 0.1.

    Two models share a name. Names are unique per project.

    PLR203¶

    Unknown source. Severity: error. Status: active. Since: 0.1.

    An input names a source that no model file declares.

    PLR204¶

    Unknown target or plugin kind. Severity: error. Status: active. Since: 0.1.

    The selected target is not in targets, or an engine, catalog, naming or sink block names a kind that no installed plugin provides.

    PLR205¶

    Duplicate source. Severity: error. Status: active. Since: 0.1.

    Two sources share a name. Names are unique per project.

    PLR206¶

    model_paths entry does not exist. Severity: warning. Status: active. Since: 0.1.

    A directory listed in model_paths is missing, so no models are read from it.

    PLR207¶

    No target selected. Severity: error. Status: active. Since: 0.1.

    Several targets exist and none was chosen. Use --target, PIPELOOM_TARGET or default_target.

    L3 graph¶

    PLG301¶

    Cycle in the graph. Severity: error. Status: active. Since: 0.1.

    Models depend on each other in a loop. The message lists the path.

    PLG302¶

    Self-reference. Severity: error. Status: active. Since: 0.1.

    A model lists itself among its own inputs.

    PLG303¶

    Selector matched nothing. Severity: warning. Status: active. Since: 0.1.

    A selector atom matched no model. This is a warning, not an error.

    PLG304¶

    Unknown selector method. Severity: error. Status: active. Since: 0.1.

    A selector uses a method other than name, tag, path or materialized. Exit code 2.

    PLG305¶

    Malformed selector. Severity: error. Status: active. Since: 0.1.

    A selector cannot be parsed, for example an empty atom or a depth of 0. Exit code 2.

    PLG306¶

    Unknown unit. Severity: error. Status: active. Since: 0.2.

    A unit: selector names a unit that the project does not have. Ephemeral models are not units.

    L4 plan semantics¶

    PLP401¶

    merge or scd2 without unique_key. Severity: error. Status: active. Since: 0.1.

    A model writes with merge or scd2 but sets no write.unique_key.

    PLP402¶

    incremental without column. Severity: error. Status: active. Since: 0.1.

    A model is materialized as incremental but sets no incremental.column to compare with the watermark.

    PLP403¶

    Aggregate expectation with drop. Severity: error. Status: active. Since: 0.1.

    An aggregate check (unique, row_count, freshness) cannot drop rows. Use warn or fail.

    PLP404¶

    incremental.input not in inputs. Severity: error. Status: active. Since: 0.1.

    incremental.input names an alias that is not one of the model's inputs.

    PLP405¶

    Write option not applied by this strategy. Severity: error. Status: active. Since: 0.1.

    A declared write option would be ignored: unique_key, update_condition or deletes with a strategy that does not use them, tracked_columns outside scd2, write on an ephemeral model, or incremental on a model that is not incremental.

    PLP406¶

    Ephemeral fan-out above threshold. Severity: warning. Status: active. Since: 0.1.

    An ephemeral model is inlined in more units than ephemeral_fanout_warn. Make it an intermediate to compute it once.

    PLP407¶

    replace_partitions without partition_by. Severity: error. Status: active. Since: 0.1.

    The replace_partitions strategy needs partition_by to know which partitions to replace.

    PLP408¶

    Ephemeral model with no consumer. Severity: warning. Status: active. Since: 0.1.

    No persisted model reads this ephemeral model, directly or through other ephemeral models, so it never runs.

    PLP409¶

    View is not a plain SQL model. Severity: error. Status: active. Since: 0.2.

    A view must be a SQL model that reads no ephemeral model, because its query is stored in the catalog as written.

    PLP410¶

    append with lookback reloads rows. Severity: warning. Status: active. Since: 0.3.

    An incremental model appends with a lookback above zero, so rows inside the window are written again. Use merge with a unique_key.

    PLP411¶

    Expectations on a view or ephemeral model. Severity: error. Status: active. Since: 0.3.

    A view or an ephemeral model writes no rows of its own, so it cannot carry expectations. Put them on a table that reads it.

    PLP412¶

    Quarantine relation collides with a model. Severity: error. Status: active. Since: 0.3.

    A model's quarantine table is named __quarantine, and another model already has that name in the same schema.

    PLP413¶

    Intermediate model with a write option. Severity: error. Status: active. Since: 0.3.

    An intermediate model is rewritten whole at a location of its own. It cannot be incremental, use a strategy other than overwrite, or set partition_by.

    L5 capability¶

    PLC501¶

    Strategy unsupported by engine. Severity: error. Status: active. Since: 0.1.

    The write strategy is not in the selected engine's capabilities.

    PLC502¶

    SQL model on an engine without SQL. Severity: error. Status: active. Since: 0.1.

    A SQL model targets an engine that cannot run SQL.

    PLC503¶

    boundary task with a non-shared state store. Severity: error. Status: active. Since: 0.1.

    Units run as separate tasks, but the state store is local to one process or machine.

    PLC504¶

    Catalog incompatible with engine. Severity: error. Status: active. Since: 0.1.

    The catalog plugin does not list the selected engine in its compatible engines.

    PLC505¶

    Non-idempotent append with retries. Severity: error. Status: active. Since: 0.1.

    An append model retries on an engine without idempotent writes, which could write the same rows twice.

    PLC506¶

    Source format unsupported. Severity: error. Status: active. Since: 0.1.

    A source declares a format the selected engine cannot read.

    PLC507¶

    View without views support. Severity: error. Status: active. Since: 0.1.

    A model is materialized as a view on an engine without catalog views.

    PLC508¶

    frame_api narwhals without portable engine. Severity: error. Status: active. Since: 0.1.

    A Python model asks for Narwhals frames on an engine whose frames are not portable.

    PLC509¶

    Materialization unsupported by engine. Severity: error. Status: active. Since: 0.2.

    The materialization is not in the selected engine's capabilities.

    PLC510¶

    Expectations on an engine without quality. Severity: error. Status: active. Since: 0.3.

    The selected engine does not declare the quality capability, so it cannot evaluate expectations.

    L6 static code¶

    PLK601¶

    Callable file or function not found. Severity: error. Status: active. Since: 0.1.

    The Python module is not under python_paths, cannot be parsed, or does not define the function.

    PLK602¶

    Callable parameters do not match inputs. Severity: error. Status: active. Since: 0.1.

    The function's parameters must be ctx followed by one parameter per input alias (any alias is accepted with **kwargs).

    PLK603¶

    SQL references undeclared table. Severity: warning. Status: active. Since: 0.2.

    A model's SQL reads a table that is neither an input alias nor a CTE. Checked only when sqlglot is installed (extra: sqlglot).

    PLK604¶

    Name bound at module level by something other than a def. Severity: warning. Status: active. Since: 0.1.

    The callable's name is bound by an assignment, import or class, so its parameters cannot be checked.

    PLK605¶

    SQL not parseable. Severity: warning. Status: active. Since: 0.2.

    sqlglot could not parse the model's SQL, so its tables were not checked. Checked only when sqlglot is installed.

    L7 preflight¶

    PLF701¶

    Engine unreachable. Severity: error. Status: reserved. Since: 0.2.

    Reserved: not emitted yet.

    PLF702¶

    Source missing. Severity: error. Status: reserved. Since: 0.2.

    Reserved: not emitted yet.

    PLF703¶

    Target schema drift detected. Severity: error. Status: reserved. Since: 0.2.

    Reserved: not emitted yet.

    Plugins¶

    PLU001¶

    Plugin API mismatch. Severity: error. Status: active. Since: 0.1.

    A plugin was built for another plugin API version. While the major version is 0 the versions must match exactly.

    PLU002¶

    Duplicate plugin kind. Severity: error. Status: active. Since: 0.1.

    Two installed plugins provide the same kind in one group, and a config names it.

    PLU003¶

    Plugin failed to load. Severity: error. Status: active. Since: 0.1.

    A plugin module cannot be imported, does not resolve to a PluginSpec, or its group or kind differs from the entry point that registered it.

    Events¶

    PLE401¶

    Sink disabled. Severity: warning. Status: active. Since: 0.1.

    An event sink failed failure_budget times in a row and was disabled. The other sinks keep receiving events and get a sink.disabled event.

    Runtime¶

    PLM201¶

    Write failed. Severity: error. Status: active. Since: 0.2.

    The engine failed to write a model's result or to create its view.

    PLM202¶

    Schema change rejected. Severity: error. Status: active. Since: 0.3.

    The batch schema differs from the existing target and the model's on_schema_change policy does not allow it.

    PLM203¶

    Watermark CAS conflict. Severity: error. Status: active. Since: 0.3.

    The stored watermark changed while the unit ran, so the new one was not saved. The data was already written. Another run on the same target is the usual cause.

    PLM204¶

    Input read failed. Severity: error. Status: active. Since: 0.2.

    An input of a model could not be read from its source or from the catalog.

    PLM205¶

    Incremental watermark unusable. Severity: error. Status: active. Since: 0.3.

    The incremental column is missing from the input, its type differs from the stored watermark, or a lookback is set on a column that is not a timestamp or date.

    PLM206¶

    Write key invalid. Severity: error. Status: active. Since: 0.3.

    A unique_key or partition_by column is missing from the batch, or a merge batch repeats a unique_key.

    PLM207¶

    Write refused by the idempotency guard. Severity: error. Status: active. Since: 0.4.

    The engine skipped the write because this model already has a later transaction version: a newer run, an overlapping run started with --no-lock, or a host clock that ran behind. The engine refuses before it changes any data. Wait for the other run, check the clocks, or turn the guard off in the engine options.

    PLQ301¶

    Expectation failed. Severity: error. Status: active. Since: 0.3.

    An expectation with on_violation: fail found violating rows, or the share of dropped rows exceeded quality.max_drop_ratio. The unit fails before writing; the counts are still recorded in run_results.

    PLQ302¶

    Expectation references an unknown column. Severity: error. Status: active. Since: 0.3.

    An expectation names a column the model output lacks, or its expr cannot be evaluated by the engine.

    PLX101¶

    Model raised. Severity: error. Status: active. Since: 0.2.

    A model's body raised, or returned a value its engine cannot use as a relation.

    PLX102¶

    Timeout. Severity: error. Status: active. Since: 0.3.

    A unit attempt ran longer than its timeout. A timed-out unit is not retried and its descendants are skipped.

    PLX103¶

    Plan hash mismatch. Severity: error. Status: active. Since: 0.2.

    The plan hash of the manifest or of the compiled project differs from --expect-plan-hash.

    PLX104¶

    Cancelled. Severity: error. Status: active. Since: 0.3.

    A unit was still running when the run was stopped and did not finish within the grace period, or the stop was hard. The run ends cancelled with exit code 130.

    PLX105¶

    Run lock held. Severity: error. Status: active. Since: 0.2.

    Another run holds the lock of this project and target. The message names the holder, its run and when its lease expires.

    PLX106¶

    Unit process exited without a result. Severity: error. Status: active. Since: 0.2.

    A unit started under boundary task exited without writing its attempt file. The excerpt holds the last lines of its log.

    PLX107¶

    Manifest invalid. Severity: error. Status: active. Since: 0.2.

    The manifest cannot be read, has another schema, was edited after it was written, or belongs to another project or target.

    PLX108¶

    Run start time conflict. Severity: error. Status: active. Since: 0.4.

    --run-started-at differs from the start the run recorded when it first ran. A reused run id keeps its recorded start. Exit code 2.

    PLX109¶

    Secret reference not resolved. Severity: error. Status: active. Since: 0.5.

    A ${secret:provider/path} reference in a plugin's options could not be resolved when the command executed: the provider is unknown or failed, the resolved options are invalid, or the plugin could not be built with them. The message names the provider and path, never a value.

    Renderers¶

    PLA001¶

    Unsupported execution mode. Severity: error. Status: reserved. Since: 0.4.

    Reserved: not emitted yet.

    PLD001¶

    Task limit exceeded. Severity: error. Status: active. Since: 0.5.

    A Databricks job would hold more than 1,000 tasks, its finalize task included. Set task_grouping in the deploy block, or split the project into pipelines.

    PLD002¶

    Submit task limit (never emitted, PLD001 covers it). Severity: error. Status: reserved. Since: 0.4.

    Reserved: not emitted yet.

    PLD003¶

    Task groups form a cycle. Severity: error. Status: active. Since: 0.5.

    With task_grouping set, the units of one group depend on units of another group in both directions, so the grouped tasks cannot be ordered. Group by another key or turn grouping off.

    PLD004¶

    Invalid Databricks deploy options for this plan or target. Severity: error. Status: active. Since: 0.5.

    The deploy block cannot be rendered: an unknown pipeline or compute key, environment_version 1, more than 10 serverless environments in a job, a key in settings that pipeloom owns, a ${secret:...} reference, an artifacts root that is unset or relative, a state store that is not shared, a group that spans two computes, or an ephemeral run on a job cluster.

    PLD005¶

    Compute rule matches no model. Severity: warning. Status: active. Since: 0.5.

    No model of the plan matches the select selectors of a compute rule, so the rule never applies.

    PLD013¶

    Dynamic value reference not resolved in a task parameter. Severity: error. Status: active. Since: 0.5.

    A parameter of a Databricks task still holds a {{...}} reference, so the platform did not substitute it. The task stops before it runs anything. Check the job's parameters and the Databricks runtime that runs the task.
